Deep Researcher

Multi-agent research system built with LangGraph. A supervisor agent breaks your question down into topics and launches search sub-agents in parallel; each one compresses its findings before handing them to a writer agent that produces the final report in markdown, with sources.

Events stream live over WebSockets, every role can use a different model, and you bring your own API keys: they are sent with the session and never stored on the server.
